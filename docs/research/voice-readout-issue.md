# feat: 伙伴语音自动播放——聊天「语音模式」让伙伴直接说话

> feature_request 模板（使用场景 / 当前问题 / 期望方案 / 替代方案）。
> 仓库 Issues 功能当前关闭（has_issues: false），开启后按此内容提交。

## 使用场景 / Use case

语音输入（听写）已经成熟：桌面聊天输入框按住说话、识别上屏、松手即发；手机端同样接入。但伙伴的回复只能「看」——用户必须盯着屏幕读。

想要的是语音对话闭环：**我说话 → 伙伴直接说话回我**。典型场景：

- 双手离开键盘（做饭、翻文档）时与伙伴推进任务，像语音通话一样对话；
- 手机远程盯着电脑上的任务时，看着别处也能听到结果；
- 长时间读屏疲劳 / 视障用户的可听化输出。

## 当前问题 / Current limitation

- 客户端没有任何 TTS 链路：模型目录里已有 `audio_speech → tts` 分类模型，但没有调用端、播放 UI 或设置项；
- Cindy 语音服务（voice.cindy.com.cn）当前只有听写 ASR 会话 + 文本润色，没有语音合成端点；
- 网关媒体代理只有图像 / 视频 provider，没有语音合成；
- 结论：语音输入的「说」已经有了，「听」完全缺失，语音对话闭环断在最后一环。

## 期望方案 / Proposed solution

### 交互

- 聊天输入框（语音按钮旁）加「语音模式」开关；开着时，每个任务收尾的伙伴回复自动朗读；
- 朗读口径与 action bar 一致：只读每 turn 收尾正文（不读过程性中间输出），markdown 剥离成可读文本（代码块 / 链接 / 表格 / emoji 剥掉），纯代码回复跳过，超长截断（~1200 字）；
- 不回放历史：开关打开前 / 关闭期间完成的回复不补读，只读「在场期间新完成的回复」；
- 互斥与打断：朗读与聊天内音视频播放互斥，新回复打断旧朗读，关开关 / 切会话即停；
- 设置页提供「语音朗读」合成模型选择（从模型目录的 tts 分类里选，含自定义供应商）；
- 两端一起：桌面（开关 + 设置页），手机（会话设置开关，音源先行系统 TTS）。

### 合成音源（分层降级）

1. 设置里选定的 TTS 模型 → 按所属供应商调 OpenAI 兼容 `/v1/audio/speech`（Cindy AI 网关或自定义供应商 BYOK，密钥不出本机）；
2. 未选定 → 探测 Cindy 语音服务内置 TTS（`POST /api/voice/sessions` `mode:'tts'` 探测式契约，服务端未部署时降级）；
3. 都不可用 → 系统 TTS（桌面 speechSynthesis / 手机 expo-speech）兜底，保证开箱可用、不登录也能用。

### 带来的体验提升

- **语音对话闭环**：说话 → 听回复，整轮任务免盯屏；
- **多设备连续性**：手机远程场景下，任务结果可「听」，不必切回屏幕；
- **无障碍**：可听化输出对视障用户与读屏疲劳用户是直接收益；
- **渐进可用**：不登录 / 服务端未就绪时系统语音兜底，配置了网关模型后音质升级，无需任何额外操作。

### 实施落点（已有一版原型实现）

- 桌面：`apps/desktop/src/main/voice-output/`（IPC + 合成客户端）、`renderer/voice-output/`（播放器 / 开关 / 自动朗读 hook）、`VoiceOutputSection` 设置区块，接线 MessageStream / ChatInput / preload；
- 共享：`packages/maker-shared/src/speechText.ts`（markdown → 可读文本，两端同源）；
- 手机：`apps/mobile/src/session/voiceReadout.ts`（偏好 + expo-speech + 自动朗读 hook）+ 会话设置开关。

## 已考虑的替代方案 / Alternatives considered

- **只做系统 TTS**：实现最简，但音质与中文语音受系统限制——保留为兜底而非主路径；
- **只接云端 TTS（等 voice-server 正式端点）**：服务端契约未定前功能完全不可用；探测式契约可先行，服务端就绪后只需对齐 `cindyTtsClient.ts` 一处；
- **只做「朗读此条」手动按钮**：每条都要点，语音对话体验不成立；语音模式开关（状态型）才是主交互，手动按钮可作为后续补充。

## 风险与备注

- 手机端 `expo-speech` 是新增原生依赖 → fingerprint 变更 → 冷更，需把关人确认；
- 自定义供应商需为 OpenAI 兼容 `/v1/audio/speech` 端点；Anthropic 协议网关无此路径时自动降级系统语音，不阻断；
- OAuth / 无鉴权形态的自定义供应商暂不支持（无可注入 Bearer key）。
