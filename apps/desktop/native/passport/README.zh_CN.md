# Cindy Passport 蓝牙

配套 ESP32-C3 固件连接 macOS Cindy。在设置 → 快捷键 → 配件 → Cindy Passport 中启用，选择发现的设备；macOS 请求时输入设备显示的配对码。菜单栏控制仍可使用。需要蓝牙权限，默认关闭。按账号隔离的 `passport-settings.json` 只保存显式覆盖，恢复默认会删除覆盖；开发环境的 `CINDY_PASSPORT_BLE=1` 设置开发默认值。其他系统显示不支持。

开发使用正式的隔离启动入口：

```sh
pnpm restart:desktop:remote --region=global --isolated=@worktree
```

开发需要 Xcode 命令行工具，打包客户端包含 Swift helper。选择的设备 ID 在 UserDefaults 中按 profile 与数据账号隔离；断开会取消自动连接，不删除 macOS/NimBLE 配对密钥。不会切换到 Wi-Fi 或 HTTP。

正式本机任务目录过滤归档及工作子任务。最多 8 个任务，依次优先等待、错误、运行、完成。已观察的完成/错误状态在活动提示清空后保留于内存，最多 100 条；适配器停止时清空。活动任务可能占满 8 个位置，不复刻远程镜像任务和侧栏顺序。

设备 UP/DOWN 选择，OK 打开详情，再按 OK 开始录音；再次 OK 发送，长按 OK 取消并退出。音频为 16 kHz 单声道、固定 16 kbit/s Opus、40 ms 分帧（每个 indication 最多 120 字节编码数据）。helper 接收蓝牙 indication，主进程检查录音标识、序号、大小、任务、账号及连接。完整录音在内存中封装 Ogg，交给 Cindy 现有批量 ASR 入口 `transcribeVoiceInputAudioFile`，可能与实时麦克风使用不同的供应商。凭证留在 Cindy。

转写完成打开原任务，只填入空白草稿；已有草稿保留，转写文字等待。用户检查后发送，不自动发送消息或审批。配件页显示录音/转写失败，设备任务详情也显示转写进度。不记录原始音频或文字日志。

服务 `C1DC0001-51C4-499D-A186-4621A4938301`：认证 RX `8302`、认证读取/通知 TX `8303`、录音 indication `8304`。任务协议仍为 v1：uint16LE 长度、版本、数量、40/80/16/192 字节 NUL 填充 UTF-8 字段。录音 v1：kind:u8、token:u32LE、sequence:u16LE；开始=1（40 字节任务 ID）、音频=2（1–120 字节编码数据）、结束=3、取消=4。序号从 0 开始，每个音频帧递增，结束/取消使用下一个序号。最多 752 帧、45 秒耗时，包含固件编码器尾部静音。录音需要两端支持，旧固件仍支持任务快照。

Ogg Opus 时间轴固定使用 48 kHz 时钟：每个 40 ms 包增加 1,920 个采样，与 16 kHz 输入采样率无关。修改主进程语音代码后，必须通过开发启动包装器重启电脑端；渲染器热更新不会替换运行中的包校验器。

主机测试及编译不能证明实物录音质量、无 PSRAM 的内存余量、权限、重连或中文显示质量。需要更新固件后人工验收，构建不会自动刷机。
